TODO. 基于HTTPS认证
通过页面用户登录并授权认证(确保特定用户)
> git config --global credential.useHttpPath true

使用API-Token替代Password进行认证(Token必须由用户生成)
> git clone https://github.com/chentong2015/JavaMasterClass.git
  Username for 'https: //github.com': chentong2015
  Password for 'https://chentong2015@github.com': API-Token

TODO. 不推荐直接使用API-Token
Token会进入.git/config文件中(默认不提交到Github)
Token可能在Remote URL显示(造成泄漏)
> git remote -v
> git remote set-url origin https://API-Token@github.com/username/project-name.git
