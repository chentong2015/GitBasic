Git会记录历史文件变更和修改数据，只要提交过则必定出现来历史记录中
Git通过.git目录保存变更过程，通过查询log可以找到文件的变更过程

查看特定文件历史Commit变更
> git log --all -- git_folder/.config

查看特定文件某次Commit修改
> git show <commit-id>:git_folder/.config
